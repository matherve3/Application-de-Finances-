Sauvegarde et conservation

Le système garde les données dans le navigateur de l’appareil. Pour conserver vos données longtemps et les utiliser sur plusieurs appareils, faites régulièrement une sauvegarde.

Pour transférer vos données : sur le premier appareil, exportez le fichier JSON. Envoyez-le à votre autre appareil, ouvrez cette page, puis choisissez « Importer une sauvegarde ». L’importation remplace les données présentes dans cette application.

Utilisation rapide

  1. Dans Opérations, saisissez chaque revenu ou dépense dès qu’il survient.
  2. Choisissez « Réalisé » pour une opération déjà effectuée, ou « Prévu » pour une estimation future.
  3. Dans Vue d’ensemble, changez l’année, le mois et le périmètre pour filtrer les résultats.
  4. Dans Épargne, créez des comptes, puis enregistrez les dépôts et retraits. Le solde est calculé automatiquement. Dans Mes projets, indiquez le budget et le montant déjà financé ; le reste à financer est calculé automatiquement.
  5. Exportez régulièrement une sauvegarde et gardez-la dans Google Drive ou un autre espace sûr.

Réinitialiser

Attention : cette action efface les opérations et projets enregistrés dans ce navigateur. Exportez d’abord une sauvegarde.
